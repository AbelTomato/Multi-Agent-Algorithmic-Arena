### 遇到的问题

- Python 3.14 下 `asyncpg` 安装和使用存在 C-API 兼容性问题；
- 本地 PostgreSQL 目标数据库最初不存在，导致 Alembic 无法连接目标数据库；
- 直接在模块导入阶段创建 PostgreSQL engine，会导致缺少 `asyncpg` 时连 SQLite 内存单元测试也无法收集。

### 解决方式

- 在 `requirements.txt` 中声明 `asyncpg==0.30.0`；
- 将 Python 环境回退至 3.12；
- 创建 `multi_agent_arena` 数据库后重新执行 migration；
- 将数据库 engine 改为在实际获取数据库 Session 时按需创建；
- 保留 PostgreSQL 集成测试的独立 `TEST_DATABASE_URL` 入口，避免误连开发库；
- 完成开发数据库和测试数据库的 migration、seed 验证。
