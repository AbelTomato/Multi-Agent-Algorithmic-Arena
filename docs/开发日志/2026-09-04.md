## 阶段 4：Solutions API、Prompt 控制与一次重试

### 完成内容

- 新增 `backend/app/schemas/solution.py`，定义解题请求和响应模型；
- 新增 `backend/app/services/solutions.py`，负责题目查询、服务端 Prompt 构建、Agent 调用和一次重试；
- 新增 `backend/app/api/solutions.py`，实现同步 `POST /api/solutions`；
- 在 `backend/app/main.py` 挂载 Solutions 路由；
- 请求体只接受正整数 `problem_id`，拒绝客户端提交的 Prompt 和其他额外字段；
- 题目不存在时返回 HTTP 404；
- Agent 连续失败时最多调用两次，并返回 HTTP 502 和脱敏错误信息；
- 不保存解题请求、Agent 结果或历史记录。

### 执行命令

```bat
.venv\Scripts\python.exe -m pytest backend -q
.venv\Scripts\python.exe -m compileall -q backend\app backend\tests
git diff --check
```

### 验证结果

- 正常解题请求返回 `problem_id`、Markdown `result` 和 `python` 语言标识；
- 服务端 Prompt 包含题目标题、题目描述、Python 和固定输出约束；
- Agent 首次失败、第二次成功时调用两次并返回成功结果；
- Agent 连续两次失败时返回受控 502 错误，不泄露 Provider 异常内容；
- 不存在题目和非法请求体均按预期处理；
- 后端测试结果：`21 passed, 1 skipped in 1.62s`；
- Python 编译检查和 `git diff --check` 通过。
