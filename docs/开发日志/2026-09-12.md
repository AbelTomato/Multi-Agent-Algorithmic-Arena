## MCP Server 受控工具补充

### 完成内容

- 在用户级 MCP Server 中新增 `run_targeted_tests`、`run_quality_checks`、`current_time` 和 `git_worktree_status` 四个受控只读/验证工具。
- `run_targeted_tests` 仅允许后端 `backend/tests` 或前端 `frontend/src` 下的测试目标，并使用固定命令。
- `run_quality_checks` 仅运行后端 Python `compileall` 和前端 `npm run build` 白名单命令，不伪造不存在的 lint/type-check 结果。
- `current_time` 默认使用 `Asia/Shanghai`，拒绝未知或格式非法的 IANA 时区。
- `git_worktree_status` 仅查询 Git 目录、分支、worktree 和改动状态，不创建、切换或删除 worktree。
- 未执行数据库 migration/seed、Git 提交/合并/推送/重置或其他外部环境写操作；保留项目原有未提交改动。
