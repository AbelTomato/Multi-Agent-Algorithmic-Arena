# 开发日志

本文目录用于记录本项目开发流程

## 目录规则

- 每个日期使用一个独立文件，文件名格式为 `YYYY-MM-DD.md`。
- 同一天的多次开发记录合并到同一个日期文件中。
- 按日期从早到晚查看历史记录，每条记录具体时间。
- 每次只记录真实发生的事情，保持简洁。
- 同时记录代码进展、环境问题、学习收获和下一步。
- 遇到错误时保留关键信息，方便以后回看和复盘。
