## 回滚总流程

发生任何异常时按以下顺序操作：

1. 立即停止继续发送评测请求，不重试 Provider 或候选容器。
2. 将 `EVALUATION_ENABLED` 设置为 `false`，使用主 Compose 入口恢复 backend。
3. 验证 backend healthy、`/health=200`、`/api/problems=200`、评测接口 `503`。
4. 等待 controller 完成当前清理；若 controller 异常，按 owner 标签精确核查，不执行无目标容器删除。
5. 确认 `io.arena.sandbox.owner=true` 容器数量为 `0`；保留异常容器 ID、日志和时间线，未经审查不得删除非精确匹配容器。
6. 如 Nginx 入口变更导致异常，恢复备份配置，执行 `nginx -t` 后 reload。
7. 如 Provider 配置泄露或异常，停用/轮换对应凭据；不在日志和报告中记录实际值。
8. 完成 `/health`、`/api/problems`、`503`、监控和敏感日志检查后才结束回滚。
